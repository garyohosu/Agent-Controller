## 1. Directive の変更（§1 / §4）

Adapter ごとに固定文を書き分けず、`worker.py` の 1 箇所に置いた。

### 共通制約（全ての意味判断 phase）

```text
Do not fill in a judgement that the formal specification and design documents do
not support. If something you need is not decided by the documents you were given,
and getting it wrong would change the behaviour, the design, or the tests
downstream, return QUESTION instead of deciding it yourself.
A QUESTION must say what is undecided, which documents you checked, and why those
documents cannot settle it.
This is not an instruction to ask more often. Wording, obvious formatting choices,
and restatements of something the documents already decide are yours to make - do
not raise those as questions.
```

最後の段落が §1 の「質問を増やすことが目的ではない」に対応する。
表記揺れや自明な形式選択は Worker の裁量のまま残した。

### Reviewer への追加（REVIEW_LIGHT / REVIEW_DEEP のみ）

```text
Do not PASS something on your own interpretation when the documents do not support
it. If the document under review states something its inputs do not decide, that
gap was filled by guessing: return QUESTION rather than accepting or silently
rewriting it.
```

適用先: `GENERATE` / `REVIEW_LIGHT` / `REVIEW_DEEP` / `FIX` / `QANDA`。

Controller 側は何も判断していない。「この曖昧さなら質問すべきだった」の判定は
一切していない（§2）。Controller がするのは、返ってきた Event の検証と遷移だけ。

## 2. 質問の指紋を直した（§10）

実 AI の 1 周で、同じ質問が 3 回出ても `NO_PROGRESS` が働かなかった。原因は 2 つ。

### (a) finding_subject が使われていなかった

```python
if finding_code:            # ← code が無いと subject を見ずに
    signature = code|subject
else:
    signature = reason      # ← 自由文へ落ちていた
```

質問は `finding_subject`（質問文）だけを持ってくるので、常に自由文の `reason` で
判定していた。実 AI の `reason` は毎回文言が変わるので、当然一致しない。

`code` か `subject` のどちらかがあればそちらを使うように直した。

### (b) phase が指紋に入っていた

`GENERATE` で聞いた質問を `REVIEW_LIGHT` で聞き直すと、別の質問として数えられていた。
実ログの Q-0001 / Q-0002 / Q-0003 は**文言まで同一**だったのに、
Q-0001 だけ phase が違うため別扱いになっていた。

**同じ質問は、誰がどの phase で出しても同じ質問。** 質問だけ phase を指紋から外した。
指摘（LOCAL_FIX など）は従来どおり phase ごとに区別する。

## 9. 残課題

1. **`CANNOT_ANSWER` を実 AI に出させていない。**
   「どの成果物にも書かれていない論点」を仕込むには SPEC を作り変えることになり、
   §8 の禁止事項（質問が出るまで入力を変えて回す）に近づく。
   質問と `CANNOT_ANSWER` だけ script し、`HUMAN_REQUIRED` から先は実物で通した。
   自然に発生した未決事項が出たときに、改めて実 AI で確認するのが筋だと考える。

2. **§8 の禁止事項に触れかけた記録。** 実 AI の 1 回目と 2 回目の間で SPEC を
   差し替えている（`result-2026-08-09-008.md` に明記）。2 回目で止め、以降は
   入力ではなく Directive を直した。指示書 002 が届く前の判断だが、記録として残す。

3. **推測禁止の副作用は未計測。** 3 回目の実行では質問が 3 回出た。
   必要な質問だったが、この設定でどれだけ質問が増えるかは 1 例しか見ていない。
   §1 の「質問を増やすことが目的ではない」が守れているかは、
   もう少し回してみないと分からない。

4. Director はまだ質問文を貼り付けるだけで、読むべき成果物を選んでいない。
