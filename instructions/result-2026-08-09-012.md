# 実施結果 012

対象: `instructions/instruction-2026-08-09-005.md` Main Graph 実配線

## 実装概要

既存のLangGraph Main Graphに `wired_handlers()` を追加し、次のトップレベル経路を実配線した。

```text
IDLE → DESIGN → IMPLEMENT → TEST → REVIEW → DOC_SYNC → COMPLETE
```

- DESIGN: 既存 `run_design()` を使用。DocumentStage内の往復はDESIGNのまま保持し、全stage完了時だけトップレベルPASSを1回適用。
- IMPLEMENT: Worker InterfaceとGit checkpointを使用し、DONE時にCODE artifactをVALID化。
- TEST: injectableなtest runnerの終了コード0だけをPASSと判定。
- REVIEW: Reviewer Workerを既存phase handler経由で実行。
- DOC_SYNC: README artifactを構造化状態 `LATEST` / `NOT_REQUIRED` に設定し、Controller側でpush。
- COMPLETE: `CompleteGate` を渡した `TransitionLogger` が必ず検証。

`handled` hookで、run_designが既に処理した中断遷移をMain Graphが二重適用しないようにした。
既存のdeterministic stub handlerは単体テスト互換のため残している。

## scripted/fake E2E

一時Git repository、bare upstream、SQLite、fake Implementer/Reviewer、終了コード0のtest runnerで実行した。

```text
IDLE → DESIGN → IMPLEMENT → TEST → REVIEW → DOC_SYNC → COMPLETE
```

確認内容:

- DESIGN内のDocumentStage遷移を圧縮するとトップレベルStateは上記順序。
- IMPLEMENT成功でCODE artifactがVALID。
- TEST/REVIEW PASSはCODE更新後にSQLite transitionへ記録。
- READMEはNOT_REQUIRED。
- Worker commit後、DOC_SYNCでpushされHEADとupstreamが一致。
- Q&A blockerなし。
- DOC_SYNC前にCODEをSTALEへ変更したケースでは `CompleteGateError` となりCOMPLETEへ入らない。
- Worker QUESTIONはQandA SQLite行を作成し、top-level HUMAN_REQUIREDへ退避できる構造を追加。
